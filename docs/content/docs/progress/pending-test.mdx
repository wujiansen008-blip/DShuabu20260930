- Canvas video task resume: starting an OpenAI-style video generation should store the remote task ID on the video node. After a page refresh, a still-pending video should keep polling automatically; if polling stopped, **Get task status** should resume with that task ID until the video is ready, the task fails, or the status request errors. 待验收：

- 竞品复刻应按“任务准备 → 竞品拆解 → 迁移方案 → 内容提示词 → 生成结果”推进：准备页分别统计商品图和参考图；分析页可修改商品事实及参考拆解；迁移页只展示可复用方法、替换映射、主动差异和画面顺序；内容页可逐图修改提示词；结果页支持画布定位、单图重做、版本切换和复刻风险检查。自动执行应直接进入结果，确认后执行应逐步确认，仅规划不应提交生图。
- 电商助手顶部应显示任务历史入口。同一画布中新建多个任务后，历史抽屉应显示任务名称、技能、状态和更新时间；切换任务应恢复对应的素材、对话、分析、方案、提示词及当前流程阶段。任务可重命名和删除，刷新页面后仍保留；删除任务或新建任务不应删除画布中的已有结果节点。
- 电商助手未选择技能时也应显示底部对话框。图片应通过输入框上方的“上传”入口直接上传或从画布选择，并以可删除缩略图展示；输入 `@` 或点击 `@` 按钮只显示匹配技能。选择技能后保留已输入需求与素材并进入对应流程。进入任一技能后，顶部技能库和输入框 `@` 入口仍可使用；切换技能时保留既有对话和当前输入，但按新技能重新开始方案流程。
- 技能分析阶段默认只应显示商品识别、已确认信息、推荐方向和未确认信息数量，完整事实、身份锁定及风险内容收进“查看完整分析”，专业策略分区默认折叠。生成完成后，右侧应直接显示大图结果卡及模型/比例信息，并支持放大、下载、画布定位、提示词展开/复制、重新编辑和仅重新生成当前图片；左侧有序结果画板应保持不变。
- 已选择的 `@技能` 标签应显示在图片上传区下方、文字输入框内部，不应出现在图片素材区域上方；点击标签仍可打开技能库进行切换。
- 当前 `@技能` 应与灰色输入提示处于同一行，底部 `@` 按钮应打开只包含技能的选择菜单。技能库应提供“全部 / 系统技能 / 我的技能”、搜索和“导入技能”；导入包含完整说明的 JSON、Markdown 或文本文件后，技能应出现在“我的技能”和 `@` 菜单中，刷新后保留，可正常调用或删除。
- 技能库的导入入口应允许选择 ZIP；导入包含 `SKILL.md` 的技能包后，应使用主标题或 frontmatter 名称和说明创建技能，在“我的技能”中显示参考文档、素材/模板和脚本数量，刷新后仍保留。进入该技能时应显示 ZIP 包摘要，并明确脚本只识别、不自动执行。缺少 `SKILL.md` 的压缩包应给出清楚错误，原有 JSON、Markdown 和文本导入保持可用。重点使用 `guizang-social-card-skill-main.zip` 验证名称、说明及资源数量。
- ZIP 技能卡应提供技能包详情入口，能够展开预览每份参考文档、查看素材/模板和脚本路径，并勾选需要参与任务的参考规则；全选和清空应立即更新已选字数并在刷新后保留。执行该技能时仅将已勾选参考文档追加到主技能规则，未勾选文档不应进入请求，任何脚本均不得自动运行。
- 技能库应提供“新建技能”；表单可配置名称、说明、默认任务、完整工作流程、补充信息字段和图片素材方式，保存后应立即出现在“我的技能”和输入框 `@` 菜单中，刷新页面后仍保留。系统技能应能复制为可修改的个人版本，自定义技能应能编辑、复制和删除。
- 自定义技能选择“仅商品图片”时应显示普通单素材入口；选择“商品图片 + 参考图片”时应自动显示两个紧凑上传入口，并分别支持本地、画布和资产库来源。双素材技能缺少任意一类图片时应阻止分析并给出明确提示，两类齐全后应正常调用技能规则生成方案。
- 在买家秀、竞品复刻及其他技能之间切换后，顶部主标题、流程状态和输入框中的 `@技能` 应全部对应当前技能；顶部不得继续显示切换前的技能名称，也不得出现任务准备卡。自定义任务名存在时可显示在副标题中。
- 新建或编辑自定义技能时，补充信息字段仍应随技能 JSON 正常保存、导出和重新导入，但调用技能后的输入区不再显示独立“需求信息”按钮；用户要求统一通过对话框提交。
- 电商助手尚未选择技能时，输入框底部应固定显示 Agent 模式、生成设置、技能库、`@` 技能、执行方式和发送按钮；技能库与 `@` 均能进入技能选择。进入技能后底栏保留技能库、创作模式、生成设置和执行操作，不再显示“需求”按钮；选择技能时应优先应用该技能配置的默认张数与比例，在窄面板中不得遮挡发送按钮。
- 输入框底部第一个机器人按钮应打开“创作类型”菜单，显示已选中的 Agent 模式，以及图片生成和视频生成；不得再打开技能库。三种类型始终留在当前画布右侧：Agent 使用技能和上下文；图片模式显示独立素材上传、图片提示词及图片设置；视频模式显示视频、图片、音频素材槽、视频提示词及视频模型设置。图片和视频每次发送均为无对话上下文的独立任务，并直接把生成配置和结果加入当前画布，不得跳转到单独工作台。书本按钮和 `@` 仅在 Agent 模式中负责技能。
- 视频模式底栏在创作类型按钮之后应依次显示模型选择、参考方式、画面比例与分辨率、视频时长四个独立按钮。模型入口可选择视频模型；参考方式包含全能参考、首尾帧和视频编辑，视频编辑应以 `edit` 模式提交；画面入口可选择比例、480p/720p/1080p 和是否生成音频；时长入口可在 4–30 秒内调整。修改均应直接用于下一次视频任务。助手首页图标、标题、说明、技能卡、输入文字、上传入口、视频素材槽和圆形工具按钮应比此前更大，在常见右侧面板宽度下文字清楚、点击区域充足且发送按钮不被遮挡。
- 渠道编辑页的视频模型应提供“视频能力”，可配置全能参考/首尾帧/视频编辑、图片/视频/音频参考、支持比例、480p/720p/1080p、最短与最长秒数及是否生成音频；保存渠道并刷新后配置仍应保留。“恢复通用能力”后不得限制选项。右侧助手切换到已配置模型时，应自动纠正不兼容的参考方式、比例、分辨率、时长和音频开关，隐藏不支持的素材槽与选项；已有的不兼容素材或设置在提交前应得到具体提示。生成到画布的配置节点应实际保存秒数、音频和水印设置。未配置能力的模型继续显示全部通用选项。
- 已配置的视频模型能力还应同时作用于画布视频设置弹层和视频工作台：只显示模型支持的分辨率、比例、时长与参考方式，支持视频编辑模式，并显示生成声音和水印开关。任何入口真正创建视频任务前都应再次校验参考图片、参考视频、参考音频、模式、比例、分辨率、时长和生成音频能力；不兼容时显示对应原因且不得请求接口。没有配置细分能力的模型保持原有通用设置和请求行为。

- 电商助手任一技能完成图片生成后，右侧结果卡应显示“存入资产库”；保存后按钮变为“已存资产”，资产库中应保留结果名称、尺寸、提示词和图片内容，重复点击不得创建相同副本。重新生成或切换到另一个结果版本后，应可将新版本再次存入资产库，并能从右侧素材入口重新选回使用。
- 渠道编辑页的每个图片模型应提供“参考图：文件表单 / 参考图：JSON”设置并在刷新后保留。OpenAI 标准图片编辑接口使用文件表单；出现 `Expected request with Content-Type: application/json` 的模型改选 JSON 后，商品图和参考图应作为 `image` 或 `images` 图片对象提交，单图及多图生成均不应再出现该媒体类型错误，且失败时不得自动重复生成。
- 电商助手进入生成结果阶段后应显示“保存已选结果”。只保存已勾选且已生成成功的图片，相同结果版本已在资产库时自动跳过并显示数量；新保存的资产应带有“AI 生成”、对应技能和方案名称标签，可通过资产库搜索再次找到。没有可保存结果时应给出明确提示。
- 电商助手生成结果卡应显示“标注图片”。打开后可在原图上拖动框选一个局部区域并填写修改要求；未框选有效区域或未填写说明时不得确认。确认后应把区域位置、修改内容及“其余内容保持不变”追加到当前图片提示词，自动展开重新编辑区，由用户确认后沿用现有“按新提示词生成”完成重做，不新增独立工作流页面。
